7-Day Morning Core Routine
A single-file, mobile-friendly, interactive checklist for GitHub Pages.
Publish with GitHub Pages
Create a new public repository on GitHub (for example, `morning-core-routine`).
Upload `index.html` to the repository root and commit the change.
Go to Settings → Pages.
Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then click Save.
Once GitHub finishes deploying, open `https://YOUR-USERNAME.github.io/morning-core-routine/`.
No frameworks, build tools, or paid hosting required. The checklist is stored in each browser's localStorage, not in GitHub. Progress is not synchronized across devices and may disappear if browser site data is cleared. A new checklist is used each Monday according to the device's local date.
